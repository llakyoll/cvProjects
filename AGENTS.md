# cvProjects

Portfolio repo of modular computer vision projects. Purpose: professional
visibility (recruiters and employers will read this repo).

- All documentation in English. Follow the `docs-standard` skill for any docs work.
- Every project folder: `README.md`, `requirements.txt`, `main.py`, `src/`, `assets/`.
- After adding/changing a project, keep the root README project table in sync.
- Quality bar: a stranger must be able to run any project in under 5 minutes.
